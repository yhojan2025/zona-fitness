1. Presentación

Zona Fitness es una plataforma web responsive para presentar el gimnasio, sus servicios, planes, horarios, espacios, productos y canales de atención. La identidad visual combina verde profundo, turquesa, fondos claros, tarjetas redondeadas y tipografías de lectura limpia.

3. Acceso y requisitos

Para visitantes solo se requiere un navegador actualizado y conexión a internet. Para mantenimiento se requiere Node.js 20+, npm, Git, PostgreSQL 18 y acceso al repositorio y a GitHub Pages.

4. Recorrido general

Encabezado y portada

El encabezado contiene el logotipo, las rutas públicas, el carrito y el acceso del equipo. En móvil se transforma en menú hamburguesa. La portada presenta el mensaje principal, llamadas a explorar planes y un carrusel con controles, progreso, textos alternativos y pausa.

Servicios, planes y horarios

El sitio presenta Cardio, zona de pesas, sauna y jacuzzi. Los planes Cobre, Bronce, Platino y Oro muestran duración, descripción y precio publicado. Horarios y ubicación incluyen mapa y fachada de Zona Fitness.

Espacio, productos, inscripción y redes

La galería presenta el ambiente aprobado del gimnasio. El catálogo informa sobre batidos, suplementación y productos para entrenar, sin procesar pagos. La inscripción comunica condiciones generales. Instagram, Facebook y WhatsApp Business presentan los contenidos publicados de Zona Fitness.

8. Experiencia móvil y accesibilidad

La interfaz fue revisada para evitar solapamientos y desbordamiento horizontal. Incluye menú hamburguesa accesible, encabezado flexible, tablas desplazables, textos alternativos, foco visible, etiquetas ARIA y soporte para reducción de movimiento.

9. Publicación, seguridad y límites

GitHub Actions compila con la base /zona-fitness/, genera 404.html y publica dist/frontend/browser. HTTPS está activo. El backend usa bcrypt, JWT, guardas de roles y validaciones de propiedad. No se almacenan tarjetas.

Alcance de entrega: los precios, imágenes, horarios y contenidos publicados corresponden a la versión aprobada de Zona Fitness.

11. Mantenimiento y actualización

  1. Editar el archivo de contenido correspondiente.
  2. Mantener textos alternativos y rutas relativas.
  3. No publicar datos comerciales sin confirmación.
  4. Ejecutar pruebas y build.
  5. Revisar escritorio y móvil.
  6. Fusionar cambios validados en main.
  7. Confirmar el workflow de Pages.
