1. Introducción

Zona Fitness necesitaba una presencia digital para comunicar servicios, planes, horarios, espacios, productos y medios de inscripción. El proyecto incluyó análisis, organización del contenido, diseño responsive, validación automatizada, documentación y publicación en HTTPS.

La versión final alcanza los objetivos definidos: el sitio está disponible, los recursos funcionan bajo /zona-fitness/, las vistas se adaptan a móvil sin solapamientos, las rutas funcionan y la documentación permite mantener la solución.

8. Flujo de navegación

Visita → Inicio → Servicios / Planes / Horarios / Espacio / Productos / Redes
                       ↓
                Crear cuenta / Iniciar sesión
                       ↓
          Carrito → Checkout → Pedido registrado
                       ↓
                 Cuenta / Tickets
                       ↓
              Admin → Gestión de usuarios

Los guards protegen checkout, cuenta y tickets; el guard de rol limita la gestión de usuarios. Las rutas desconocidas vuelven a la landing.

La autenticación usa guards e interceptor; la interfaz separa el sitio promocional del soporte interno; la compilación utiliza --base-href /zona-fitness/ y crea un fallback SPA.

10. Responsive, accesibilidad y seguridad

  • Revisión en 320, 360, 390 y 430 px, tableta y escritorio.
  • Tarjetas, formularios, tablas, botones e imágenes se adaptan al contenedor.
  • Enlace para saltar al contenido, ARIA, alt, foco visible y teclado.
  • Guards de sesión y rol; no se almacenan tarjetas ni se simulan cobros.
  • HTTPS activo mediante GitHub Pages.

14. Conclusión

Zona Fitness demuestra la conexión entre análisis, diseño, desarrollo, QA y despliegue. Todas las metas de esta versión fueron alcanzadas: la navegación funciona, el contenido está organizado, las vistas móviles no presentan overlap, las rutas internas están protegidas, la documentación está disponible y la aplicación está publicada con HTTPS.

Una solución web terminada se define por su código, pero también por la claridad de sus responsabilidades, la trazabilidad de sus decisiones, la evidencia de sus pruebas y la capacidad del cliente para recibirla y mantenerla.
